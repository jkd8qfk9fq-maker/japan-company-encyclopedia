運営者の指示（2026-11-19）: 参入しやすさの高い領域を具体化して実装を進める。就活は企業タイプ診断への

分担の現状: 分析・企画は Muse、実装作業は Claude Code（2026-11-17 運営者）。本書はその共有用。
JCE-071 の実装は Muse 側でも着手済み（このブランチ feature/jce-071-072）。着手前にブランチの状態を確認し、

## 3. 就活 × 企業タイプ診断（-MBTI）— 分析結果: すでに深く盛り込まれている

診断側の決定で確認済み: CTS-030（企業の募集ページ原文を検証した就活アドバイス、プレミアム）、
CTS-031（会社さがし適応型 18〜40問）、CTS-037/038/039（企業分析・企業からの見られ方・ESの書き方を含む
印刷用ワークブック、書き込みシート分離）、CTS-043（マッチ産業 → 百科事典の就活読書順序 #job-path）、
CTS-045（産業タイプマップ）。

残る穴は2つ:
1. 会社さがし・企業分析が対象にできるのは4軸で分析済みの約80社のみ。百科事典の3,900社と桁が違う。
   分析済み企業の拡充が供給網側の課題。
2. 診断結果 → フォロー → 開示アラートが就活の文脈（志望企業の決算・訂正を追う企業研究）として
   つながっていない。JCE-071/072 の導線で埋める。

## 4. BtoB — 印刷できるプレミアムサマリー＋比較分析（品質を高めてから作る）

実サービスの調査結論: 買われているのはデータではなく「型別の判断の代行」。

- 与信型（TDB／TSR）: TSR REPORT の冒頭1枚（評点・評点推移 最大7世代・業績3期＋今期見込・リスク
  スコア・業界順位・所見）が印刷サマリーのベンチマーク。受容価格帯: 報告書全文 PDF 15,000〜30,000円／件。
  両社とも第三者開示禁止 — 「印刷して外に出せる許諾」自体が差別化になる。
- IR型（シェアードリサーチの実物構成）: 要約 → 四半期・セグメント別業績 → 会社予想 → 中計 → 事業詳細
  → 収益性分析 → 市場とバリューチェーン → 競合特定＋主要競合の財務比較 → 強み弱み → 長期財務・大株主。
  企業が伝えたがるのは中計の進捗・市場規模とシェア・自社の強み弱み。
- 経営企画型（SPEEDA の Comps）: 横並び表＋時系列（対ピア中央値）＋散布図（成長×収益性）＋ランキング
  の3点セット。財務は標準化10年超。

自社の強み（調査の対照表より）: 全数値が出典IDで原典まで検証可能（他社は取材・混合出典で不可）、
5期印字値の正確さ、セグメント別・地域別売上の全社一貫保有、上場3,900社・単一定義・毎日更新による
ピア母集団の完全性。

### 哲学フィルター（百科事典の不変条件が優先。ここを外さない）
- 採らない: 株価・時価総額・PER/PBR 等のバリュエーション追加（不変条件4）。独自の信用評点・倒産確率の
  創作（検証可能性という信頼資産を毀損する）。キーマン個人情報・インテントデータ。非上場への拡張。
- 採る（優先順）:
  1. 計算指標レイヤー: 印字値から計算した指標に「計算値」と明記し、業界の中央値・四分位・順位・
     パーセンタイルを併記する（新規データ不要で Comps の列が立つ）
  2. セグメント利益・マージンの抽出（有報のセグメント情報から）
  3. 大株主・所有者別・役員（有報から回収可能）
  4. 会社予想・中計（出典を決算短信へ広げる場合は「有報検証済み」とバッジを分ける表示設計が条件。
     四半期は保有済みのため予想進捗率の自動更新が可能で、年8回更新のスポンサードリサーチに鮮度で勝てる）
  5. 設備投資・減価償却・R&D（有報から）
  6. 有報のリスク・MD&A の出典付き要約による強み弱みの原案（解釈層は「編集部の提案」と明示する）
- 価格の考え方: 読み手向け単発は与信 PDF の 15,000〜30,000円帯が目安。「自社資料として配りたい
  発行体」向けは桁が変わるため、英語版・四半期自動更新・第三者提示許諾をパッケージ化する。

## 5. 基盤の原則（全サービス共通）

新サービスは独立した事業ではなく、百科事典の供給網（出典検証済みデータ＋毎日更新パイプライン）の
出口である。出口が増えるほど基盤の価値が上がり、基盤の検証品質が全出口の差別化になる。
逆に、基盤の哲学（出典拘束・印字値・株価なし・作り話なし）を崩す出口は、短期収益でも作らない。
