### revenueBasis / netIncomeBasis / note の判断

**`revenueBasis` / `netIncomeBasis` は設定しなかった。`note` を2年度に付けた。**

`indicators.txt` の注に、過年度に遡及した変更が2件ある。

- 注4：第133期において**リース債権に係る貸倒引当金の測定方法を変更**し、第132期の連結経営指標等は当該会計方針の変更を
  遡及適用した後のもの。
- 注5：第134期において**IFRS第17号「保険契約」を適用**しているほか、第133期に取得したエスコーツ Ltd.（現 エスコーツ
  クボタ Ltd.）に係る**暫定的な会計処理を確定**しており、第133期の連結経営指標等はこれらの影響を遡及修正した後のもの。

判断と理由：どちらも**測定方法・会計方針の変更**であって、売上高や純利益が覆う**範囲（パーミター）の変更ではない**。
非継続事業への振替、子会社の連結除外、取得を遡及的に表示し直した組替えのいずれも起きていない。エスコーツは2022年4月の
取得日から連結しており（沿革）、注5は取得対価の暫定処理を確定した測定調整であって、取得を過年度に遡って連結し直した
ものではない。よってチャートを分断する `revenueBasis` / `netIncomeBasis` は付けず、読者が年度を正しく読むための
`note` を、遡及の対象になった **2021年12月期（注4由来）と 2022年12月期（注5由来）** にそれぞれ1文で置いた。

なお当期は「2025年1月1日付の機構改革に基づき事業セグメントの構成を変更し、従来『調整』に含めていた一部の費用を各事業
セグメントに含め」、比較情報も組替えて表示している（`segments.txt`・`md-and-a.txt`）。これは**セグメント区分内の費用配賦の
変更**で、連結の売上高・純利益には影響しないため財務の basis 対象外。ただしセグメント利益の前年度比が組替え後の数値で
算定されている点は、各事業の `description` で「前年度比」を引用する根拠として確認した。

## Gaps and judgement calls

1. **沿革の形式**：`history.txt` は「1890年２月創業者 久保田権四郎 大阪市南区御蔵跡町に…」のように、**年月が各事象の
   直前にインラインで印字される形式**だった。年セルが事象と分離して出力される形式ではないので、**沿革だけで日付が確定でき、
   フィリング内の第二のソースは不要**と判断した。
2. **1961年の項目**：沿革のセルは「1961年５月水道研究所を新設。翌年12月水処理事業部を新設し、環境事業に本格進出。」で、
   環境事業への本格進出は1962年12月にあたる。`year` はセルの年（1961）とし、`title` と `description` に「翌1962年12月に
   水処理事業部を新設」と明記して両方の年が読めるようにした。年を1962に付け替えると水道研究所の年がずれるため。
3. **機械の子事業の順序**：上記「Segment ordering」のとおり、農業機械とエンジンを分けた売上高が開示されていないため
   売上高順にできず、有報の主要品目掲載順を採った。
4. **`listings`**：ニューヨーク証券取引所（1976年上場・2013年上場廃止、沿革）は enum 外かつ現在の上場ではないため
   `listings` に入れず、この log に記録した。
5. **訂正有価証券報告書2件（第135期・第134期）の内容未確認**：上記「修正再表示チェック」に理由を記載。数値は最新有報の
   5年表を採用し、前期有報との6項目一致を確認済み。
6. **短信のクロスチェックは未実施**：有報XBRLのタグ値と `indicators.txt` の印字が全項目一致し、齟齬がなかったため。
7. **`sources` の id は `yuho-2026`**：`draft-entry.json` の `sourceIds` に合わせた。指す文書は**2026年3月16日提出の
   第136期（2025年12月期）有価証券報告書**で、会計年度ではなく提出年に由来する id であることを明記する。
8. **`industries`**：`INDUSTRY_IDS` に機械・農機に対応する id がないため、コマツと同じ `construction` を primary 1件とした。
