### どのタグ候補を採ったか（pack の警告2件への回答）

pack は revenue に2候補、netIncome に2候補があると警告している。

**revenue**
- `jpcrp_cor:RevenueIFRSSummaryOfBusinessResults`（taxonomy ラベル「売上収益（IFRS）」）… 2024/2025/2026年3月期
- `jpcrp_cor:NetSalesSummaryOfBusinessResults`（taxonomy ラベル「売上高」）… 2022/2023/2024/2025年3月期

**netIncome**
- `jpcrp_cor:ProfitLossAttributableToOwnersOfParentIFRSSummaryOfBusinessResults`… 2024/2025/2026年3月期
- `jpcrp_cor:ProfitLossAttributableToOwnersOfParentSummaryOfBusinessResults`… 2022/2023/2024/2025年3月期

**採った方針**: 有報がその年度について掲げている最新の基準の行を採る。
- 2024年3月期・2025年3月期は両方の行が印字されているが、有報が先頭に置き、かつ会社が現在よって立つ基準である
  IFRS の行（売上収益／親会社の所有者に帰属する当期利益）を採った。日本基準の表の第159期には
  「金融商品取引法第193条の２第１項の規定に基づく監査を受けていません」という注記があり、
  同じ年度で監査済みなのは IFRS 側である点も根拠にした。
- 2022年3月期・2023年3月期は IFRS の数値が存在しない（移行日が2023年4月1日で、IFRSの表のこれらの列は「－」）。
  日本基準の行（売上高／親会社株主に帰属する当期純利益）を採るほかない。
- 2026年3月期は IFRS のみ。

ラベルは taxonomy 名ではなく `indicators.txt` の印字（「売上収益」「売上高」「親会社の所有者に帰属する当期利益」
「親会社株主に帰属する当期純利益」）を使った。純利益はいずれも親会社帰属の行で、包括利益の行
（「親会社の所有者に帰属する当期包括利益」「包括利益」）は採っていない。

### 修正再表示チェック — 数値の修正再表示は**なかった**

pack の `restatementCheck` は前期有報（第159期・docID `S100W4MT`）と当期有報を機械比較しており、結果は次のとおり。

```
revenue:   comparedRows 4, differences []
netIncome: comparedRows 7, differences [
  { key: "当期利益又は当期損失（△）：親会社の所有者に帰属（IFRS）|2023-03-31",
    previousFiling: null, latestFiling: null }
]
```

**差異として挙がった1件は、前期も当期も値が `null`** である。これは IFRS の表の
**移行日（2023年4月1日）の列**にあたり、主要な経営指標等の推移でも「－」と印字されている。
移行日の列には持分・資産合計・現金及び現金同等物といった残高項目だけが入り、
売上収益や当期利益のようなフロー項目は前期有報にも当期有報にも存在しない。
したがってこれは**金額が書き換わった修正再表示ではなく、値のない列どうしの比較が差異として拾われたもの**である。
重なる年度の実数は、売上4行・純利益6行すべてが前期有報と一致している
（例：日本基準 2024年3月期 売上高 5,374,255百万円、2025年3月期 5,843,087百万円は両有報で同一）。

**旧値・新値**: 該当なし（旧 `null` → 新 `null`）。金額の変更はない。

**`revenueBasis` / `netIncomeBasis` を置くかの判断 → 置かない。**

- 修正再表示が存在しないので、「連結範囲の変更（perimeter change）」も「誤謬の訂正・組替」も起きていない。
  富士通・セブン＆アイのように basis を全年度に置いて棒グラフを分断する理由がない。
  KDDI のように訂正内容を `note` に書く理由もない（訂正されていないため）。
- 一方、この5年には **日本基準 → IFRS という会計基準の変更**という、読者が知らなければ誤読する断絶が実在する。
  これは `revenueBasis` ではなく `accountingStandard` が表す事象で、ページ側は既にこれを扱う:
  `src/lib/charts/financial-chart-geometry.ts` は連続する年度で `accountingStandard` が変わると
  reason `"standard"` でグラフを分断し（`revenueBasis` の変化は別の reason `"basis"`）、
  `src/components/company/financial-section.tsx` は基準が複数あるとき
  「会計基準が異なる年度を含みます（日本基準・IFRS）。基準をまたぐ年度の数値は、厳密には比較できません。」を、
  売上ラベルが複数あるとき「売上にあたる項目の名称が年度により異なります（売上高・売上収益）。」を表示する。
  `accountingStandard` を年度ごとに正しく入れるだけで断絶は正直に表示されるため、
  `revenueBasis` を重ねて置くのは、起きていない集計範囲の変更を主張することになる。
- 代わりに、基準が重なる2年度（2024年3月期・2025年3月期）に `note` を置き、同じ有報の日本基準の表が示す
  売上高・親会社株主に帰属する当期純利益を出典付きで明記した。金額差は
  2024年3月期で売上 −16,732百万円・純利益 +49,300百万円、2025年3月期で売上 −17,926百万円・純利益 +25,884百万円である
  （差額は本ログでの引き算であり、entry には書いていない）。

## Gaps and judgement calls

1. **「修正再表示あり」の警告は実体がなかった** — 上記のとおり `null` 対 `null`。数値の修正再表示はゼロ。
   したがって basis フィールドは置かず、修正再表示を説明する `note` も書いていない。
   タスク指示は「1件の数値が修正再表示されている」という前提だったが、pack の証拠はそれを支持しない。
   存在しない訂正を entry に書くことはしていない。
2. **基準の断絶は `accountingStandard`（jgaap×2 → ifrs×3）で表現した。** 上記の判断理由を参照。
   この entry は、既存企業で初めて日本基準と IFRS が混在する entry になる。
3. **2024年3月期・2025年3月期にどちらの系列を採るか** — IFRS を採った。理由は上記（有報の先頭の表・
   現在の基準・日本基準側の第159期は監査未了）。日本基準の金額は `note` に残したので、
   日本基準の資料と突き合わせる読者も迷わない。
4. **短信によるクロスチェックは未実施。** 有報本文（経営者による分析）の億円表記が XBRL タグ値と一致することを
   確認したのみ。pack に短信は含まれていない。
5. **過去・海外の上場は `listings` に入れていない**（enum が tse/nse/fse/sse のみで、いずれも上場廃止済みのため）。
   沿革が記録しているもの: 1949年5月 東京・大阪・名古屋各証券取引所に上場（大阪・名古屋は2003年3月に上場廃止）、
   1954年5月 福岡証券取引所に上場（2002年8月に上場廃止）、1987年3月 アムステルダム証券取引所に上場
   （1999年5月に上場廃止）。2022年4月に東証の市場区分見直しでプライム市場へ移行。
6. **`relatedCompanies` は空**（別パスで調査する方針のため）。沿革にはトヨタ自動車、SUBARU、
   Maruti Suzuki India Ltd. など関係の記載があるが、この entry では扱っていない。
7. **投資指標は一切書いていない。** 有報の主要な経営指標等の推移には親会社所有者帰属持分当期利益率や
   株価に関する指標、1株当たりの金額が並ぶが、いずれも entry には転記していない。
8. **企業サイト・統合報告書は参照していない。** 有報だけで description、事業、ビジネスモデル、沿革が
   すべて賄えたため、出典は yuho-2026 の1件。
