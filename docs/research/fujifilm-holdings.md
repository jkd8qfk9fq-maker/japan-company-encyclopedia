### revenueBasis / netIncomeBasis — 設定していない

**判断: 連結範囲の変更にあたる事象がないため、両方とも省略した。**

当年度に起きたセグメント関係の変更は、MD&A（事業セグメント別の営業利益表の脚注）にある
「当連結会計年度より、AF（アドバンストファンクショナル）材料事業に含まれていたケミカル試薬を
エレクトロニクスセグメントからヘルスケアセグメントへ移管しております。前連結会計年度のセグメント情報は、
変更後の区分方法により作成したものを記載しております。」の1件だけである。

これは**セグメント間の付け替え**であって、連結の範囲（何を連結売上高に含めるか）の変更ではない。
連結売上高・連結利益の5年系列が測っている対象は変わらない。修正再表示チェックで過年度の6項目に
差がないことも、これを裏づける。したがって basis は付けず、**`note`（2026年3月期）に1文だけ書いた**。
セグメント別の数字を前年と比べる読者に必要な情報だが、チャートを切る事象ではない。

沿革にある買収（2023年10月 CMC Materials、2025年1月 合弁設立、2026年3月 ETG）はいずれも
5年の売上高の比較可能性を壊す規模として会社が説明しているものではなく、遡及的な再表示も行われていない。

## 沿革の形式チェック

`history.txt` は「年月」が**各事項の直前にインラインで印字される**形式だった
（例:「1934年1月写真フィルム製造の国産工業化計画に基づき……」「2026年3月トルコのITサービス企業
ETG Global Information Technology Services Inc.を買収。」）。年セルが事項と分離して出力される形式では
ないので、日付のずれは起きえない。**沿革は単独で健全**と判断し、フィリング内の第二のソースによる
突き合わせは行っていない。

## Gaps and judgement calls

1. **セグメント数値を `md-and-a.txt` から採った**（上記）。セグメント情報の TextBlock が有報の XBRL に
   なく、`notes-usgaap.txt` は3万字で打ち切られている。欠落部分は根拠に使っていない。
2. **`revenueBasis` / `netIncomeBasis` を設定しなかった**（上記）。ケミカル試薬のセグメント間移管は
   連結範囲の変更ではないため。`note` で1文だけ触れた。
3. **`industries` の primary を `electronics` にした**。有報は業種を宣言していないので、これは
   百科事典側の分類判断である。内視鏡・複合機・デジタルカメラといった機器が売上の中心で、
   キヤノン・ニコンも `electronics` primary であることと揃えた。半導体材料・ディスプレイ材料を
   `chemicals`、医薬品・バイオCDMOを `pharmaceuticals` として副次に付けた。
4. **セグメント間の内部売上高が分からない**。MD&A の表は「連結売上高」で、日立やパナソニックの
   エントリーのような「セグメント間取引を含む計」は開示されていない。そのため businesses の
   description には外部向けの連結売上高だけを書いた。
5. **地域別売上高の内訳が国内／海外の2区分しかない**。セグメント情報の地域別開示が取れないため、
   MD&A の国内・海外の2つだけを使った。国別は書いていない。
6. **2026年度の業績見通し（MD&A ③）は使っていない**。将来の予想であり、百科事典の記述対象ではない。
   同じ表にある ROE / ROIC も投資指標として不使用。
7. **株主還元方針（配当性向の目安）は使っていない**。投資向けの情報であり、掲載禁止項目にあたる。
8. **短信・統合報告書・会社サイトを参照していない**。有報だけで裏づけられたため。
9. **`relatedCompanies` は `[]`**（protocol どおり、別パスで調査）。
10. `status` は `published`。null のままにした数値はない。

## 検証ツールでブロックされている点（データの問題ではない）

```
node scripts/research/verify-financials.mjs fujifilm-holdings   →  exit 1
不一致 5 件（5年とも同じ）:
  「当社株主帰属当期純利益」に親会社帰属の明示がありません。
  非支配株主分を含む当期純利益と区別できないため、有報の表記をそのまま使うこと
```

`npm run content:validate-file -- src/data/companies/fujifilm-holdings.json` は **exit 0**。

**原因**: `scripts/research/verify-financials.mjs` の

```js
const PARENT_ATTRIBUTION = /((親会社|当社)の?(株主|所有者)に帰属|当社に帰属)/;
```

が「**に**帰属」を必須にしている。富士フイルムの有報が印字しているのは
「当社株主**帰属**当期純利益」で、「に」がない。既存の US GAAP 採用会社（キヤノン・コマツ・
野村ホールディングス）はいずれも「当社株主に帰属する当期純利益」と印字しており、
この正規表現はその3社の表記に合わせて書かれている。

**これはデータの誤りではない**:

- `indicators.txt` の印字が「当社株主帰属当期純利益(百万円)」であることを grep で確認済み。
  有報は「に帰属」という表記をこの表のどこにも使っていない。
- XBRL 要素は `jpcrp_cor:NetIncomeLossAttributableToOwnersOfParentUSGAAPSummaryOfBusinessResults`
  の1件のみで、taxonomy ラベルは「当社株主に帰属する純利益又は純損失（△）（US GAAP）」。
  親会社帰属の当期純利益であることに曖昧さはない。
- 包括利益の行（当社株主帰属当期包括利益）とは別の行を採っている。

**ラベルを書き換えて通すことはできない**。同スクリプトの別の規則（127行目）が
「ラベルが有報の主要な経営指標等の推移に印字されていること」を要求するため、
「当社株主に帰属する当期純利益」に直すと今度はそちらで落ちる。**両方を満たす文字列は存在しない**。
つまりこれはツール側の取りこぼしであり、データを曲げて回避すべきものではない。

**想定される修正（プロジェクトリードの判断で）**: 正規表現に「に」を任意にする1文字の変更。

```js
const PARENT_ATTRIBUTION = /((親会社|当社)の?(株主|所有者)に?帰属|当社に帰属)/;
```

タスクの指示により、スクリプト・型・テストには一切手を入れていない。
