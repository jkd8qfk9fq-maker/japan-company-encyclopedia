- **ラベルの確認**: `indicators.txt` の印字は「売上高」「税引前利益」「親会社の所有者に帰属する当期純利益」
  「資産合計」「資本合計」「従業員数（外、平均臨時雇用者数）」。draft のラベルはこれと一致していたので
  そのまま採った。`revenueLabel` を IFRS だからと「売上収益」に直すことはしていない — パナソニックは
  IFRS 適用会社だが五年表に印字しているのは「売上高」である。
- **`netIncome` の取り違え確認**: 同じ表に「親会社の所有者に帰属する当期包括利益」（2026年3月期 638,024百万円）が
  並んでいる。採用したのは当期純利益 189,540百万円のほうで、包括利益ではない。
- **`netAssets`**: 「資本合計」（非支配持分を含む総額）を採用。表には「親会社の所有者に帰属する持分」
  （2026年3月期 5,211,272百万円）も印字されているが、protocol どおり総額を優先した。
- **`employees`**: 五年表の「従業員数（外、平均臨時雇用者数）（人）」の本数値。括弧内の平均臨時雇用者数
  （2026年3月期 24,703人）ではない。brief の従業員表には 2026-03-31 の行が2回出力されているが、値は同一で
  影響なし。
- **会計基準**: `cover-page.txt`「会計基準、DEI」= IFRS。五年表の注記も「当社は、国際財務報告基準（以下、
  「IFRS」）に基づいて連結財務諸表を作成しています」。5年とも `ifrs`。
- **修正再表示**: brief の 修正再表示チェックは「前期有報と重複年度は全て一致（修正再表示なし・8行）」。
  `summary.json` の `restatementCheck` でも revenue / netIncome / profit / totalAssets / employees が各4行、
  netAssets が8行を比較して差分ゼロ。突き合わせられる行がなかった項目はない。修正再表示はない。
- **短信クロスチェック**: 実施していない。有報のタグ値と印字が6項目×5年で一致しており、齟齬がないため。

### revenueBasis / netIncomeBasis — 設定した（全5年）

**判断: 連結範囲の変更（deconsolidation）にあたるため、両方を全年度に設定してチャートを切った。**

根拠（`segments.txt` /「セグメント情報」(1)報告セグメントの概要）:
「2024年12月２日付でパナソニック オートモーティブシステムズ㈱（以下、「PAS」）の株式譲渡が完了した
ことに伴い、当連結会計年度より「オートモーティブ」セグメントは当社の報告セグメントに該当しない
こととなりました……「オートモーティブ」は、PASの株式譲渡に伴い非連結化した事業の非連結化するまでの
期間（前連結会計年度については約８か月分）の売上高及び損益で算出しています。」

- 2022〜2024年3月期: PAS を通年で連結。
- 2025年3月期: 2024年12月2日までの約8か月分のみ連結。当該期間のオートモーティブセグメント売上高
  （セグメント間取引を含む）は 804,970百万円。
- 2026年3月期: PAS を含まない。

**非継続事業としての遡及再表示は行われていない**（修正再表示チェックで過年度の売上高・純利益に差が
ないことがその裏づけ）。つまり過年度の数値は PAS を含んだままで、2026年3月期だけ含まない。
5年の売上高が測っている範囲が同一でないので、基準を揃えずに折れ線で結ぶと誤読させる。
これは測定方法の変更（`note` で足りるケース）ではなく連結範囲そのものの変更なので、
`revenueBasis` と `netIncomeBasis` の両方を全5年に入れた。

### note

- 2025年3月期: PAS 株式譲渡の完了日と、非連結化までの約8か月分のオートモーティブセグメント売上高。
- 2026年3月期: 会社自身が MD&A (3)① ② で述べる減収・減益の理由（前年度のオートモーティブ事業の
  非連結化の影響、PHS株式譲渡益、インフレによる固定費増加、戦略投資の増加、グループ経営改革に関する
  構造改革費用）。会社の説明としてそのまま書き、評価は加えていない。

**判断（その他の置き場所）**: 「その他」の売上高 1,414,633百万円は6つの報告セグメントのどれより大きいが、
これは報告セグメントではなく「報告セグメントに含まれない事業セグメントやその他の事業活動」の残余区分で、
旧オートモーティブの連結継続分と住宅設備・建材が入っている。売上高順に並べて先頭に置くと、
パナソニックの主力が住宅設備・建材であるかのように読めてしまう。したがって
**報告セグメント6つを売上高「計」の降順に並べ、「その他」は末尾に置いた**。会社が「その他」の中身
（水まわり設備、内装建材、外装建材、原材料の販売等）を明記しているので、掲載自体はしている。

**判断（セグメント区分）**: 2026年1月1日付のグループ体制再編で、従来の「くらし事業」「オートモーティブ」
「コネクト」「インダストリー」「エナジー」の5区分が、現在の「コネクト」「エレクトリックワークス」
「HVAC & CC」「エナジー」「インダストリー」「スマートライフ」の6区分に変わった。この変更は当連結会計年度
（2026年3月期）内に発効しており、有報のセグメント情報そのものが新6区分で、前年度も組み替えて表示されて
いる。したがって新6区分をそのまま最上位に採った（決算期後の新体制を先取りする Mitsubishi Corporation の
ケースとは異なり、推測は不要）。

**オートモーティブ**: 当年度は全項目ゼロで、会社も「当社の報告セグメントに該当しないこととなりました
が、明瞭性を高める観点から引き続き表示しています」としている。現在の事業構造ではないので
`businesses` には入れていない。

**children**: 置いていない。事業の内容・セグメント情報とも各セグメントを製品の列挙で説明しており、
会社自身が下位の事業区分を階層として示していないため。MD&A にはセグメント内の事業名
（アビオニクス事業、プロセスオートメーション事業、ブルーヨンダー事業など）が出るが、
これは当年度の業績説明の単位であり、有報が構造として定義しているものではないので階層化しなかった。

## 沿革の形式チェック

`history.txt` は「年月」と「事項」が**各イベントの直前にインラインで印字される**形式だった
（例:「1918年３月松下幸之助により大阪市福島区大開町に松下電気器具製作所を設立」「2024年12月事業会社の
一つであるパナソニック オートモーティブシステムズ㈱の全株式を譲渡し……」）。年セルが事項と分離して
出力される形式ではないので、日付のずれは起きえない。**沿革は単独で健全**と判断し、フィリング内の
第二のソースによる突き合わせは行っていない。

## Gaps and judgement calls

1. **`revenueBasis` / `netIncomeBasis` を全5年に設定**（上記）。PAS の非連結化は遡及再表示されておらず、
   5年の売上高・純利益が同じ連結範囲を測っていない。チャートは切れるべきと判断した。
2. **「その他」を売上高順ではなく末尾に配置**（上記）。順序の根拠となった数値は上表に全部載せた。
3. **オートモーティブセグメントを `businesses` に入れなかった**。当年度の売上高・損益がゼロで、
   報告セグメントに該当しないと会社自身が述べているため。ただし5年チャートの読み方に直結するので、
   `financials` の basis / note と沿革 2024年に書いた。
4. **2026年4月の3事業会社発足（パナソニック HVAC & CC㈱、パナソニック エレクトリックワークス㈱、
   パナソニック㈱）を entry に書かなかった**。MD&A (3) に記載はあるが、これは決算期後の事業会社の
   再編であり、報告セグメントの区分（2026年1月1日付で変更済み）は変わらない。セグメント構造の
   記述に影響しないため、事実を増やさない側に倒した。
5. **2026年3月のパナソニック ハウジングソリューションズ㈱株式80％譲渡**。沿革の最終行にあるが、
   期末直前の出来事で当年度のセグメント情報は依然「その他」に住宅設備・建材を含んでいる。
   沿革の項目としては採らず、2026年3月期の `note` の中で会社の減益要因の説明の一部として触れた。
6. **`children` なし**（上記）。会社が階層を示していないため。
7. **短信・統合報告書・会社サイトを参照していない**。有報だけで description / businesses /
   businessModel / history のすべてを裏づけられたため、二次的な取得はしていない。
8. **`relatedCompanies` は `[]`**（protocol どおり、別パスで調査）。
9. `status` は `published`。null のままにした数値はない。
