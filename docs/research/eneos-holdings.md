### 修正再表示チェックの読み方 — **重要**

`verify-financials.mjs` は「前期有報との比較: 28 行一致（修正再表示なし）」と出ます。28行の突き合わせが成立しているので「突き合わせられる行がない」ではありません。

**しかし、この結果は「組み替えが起きていない」ことを意味しません。** 組み替え（第14期＝2024年3月期の売上高・営業利益・税引前利益を継続事業のみに組み替え）は**前期の有報（第15期）で既に行われている**ため、前期有報と当期有報を比べれば当然一致します。pack の比較は「直前の有報との差」しか見られないので、この種の組み替えは構造的に検出できません。

実際の組み替えは、この有報自身が `indicators.txt` 注2 で明記しています。

> ２．2025年３月19日において、当社の子会社であったJX金属株式会社（以下、JX金属）が東京証券取引所プライム市場に新規上場しました。株式上場に際し、当社が保有するJX金属株式の一部につき売出しを行ったことにより、JX金属及び同社子会社等からなる金属事業を**非継続事業に分類**しています。これに伴い、**第15期の売上高、営業利益及び税引前利益については、非継続事業を除いた継続事業の金額を記載しており、第14期の数値も同様に組み替えて表示しています。**また、第16期における金属事業の持分法による投資利益は継続事業として含めています。

つまり第14期（2024年3月期）と第15期（2025年3月期）は継続事業のみ、**第12期（2022年3月期）と第13期（2023年3月期）は組み替えられておらず金属事業を含んだままです**。第16期は金属事業が持分法による投資利益として継続事業に入ります。

### `revenueBasis` / `netIncomeBasis`: **SET on all five years** — decision and reason

これは perimeter change そのものです。非継続事業への分類（IFRS 第5号）と子会社の支配喪失（deconsolidation）が同時に起きており、5年のあいだで売上高が覆う範囲が2回変わります。task の規則どおり **`revenueBasis` と `netIncomeBasis` を全5年に置きました**ので、ページはチャートを割り、どの年の列が別の範囲を測っているかを示すはずです。

| fiscalYear | revenueBasis | netIncomeBasis |
|---|---|---|
| 2022年3月期 | 金属事業（JX金属）を子会社として含む | 同左 |
| 2023年3月期 | 金属事業（JX金属）を子会社として含む | 同左 |
| 2024年3月期 | 金属事業を非継続事業として除いた継続事業のみ（2025年3月期の分類に合わせて組み替え） | 継続事業と非継続事業（金属事業）を合わせた当期利益。有報が継続事業に組み替えたと注記しているのは売上高・営業利益・税引前利益のみ |
| 2025年3月期 | 金属事業を非継続事業として除いた継続事業のみ | 同上 |
| 2026年3月期 | 継続事業のみ（金属事業はJX金属の持分法による投資利益として「その他」の区分に含む） | 同左 |

**`netIncomeBasis` が `revenueBasis` と違う理由。** 注2 が継続事業に組み替えたと言っているのは**売上高・営業利益・税引前利益の3行だけ**で、当期利益の行についてはその記載がありません。IFRS の表示では当期利益は継続事業と非継続事業の合計になるので、2024年3月期と2025年3月期の 親会社の所有者に帰属する当期利益 は金属事業の損益を含んだままと読むのが自然です。注記15 は非継続事業からの当期利益を2025年3月期 229,569百万円（2026年3月期は「－」）と別掲しており、この額には支配喪失により生じた売却関連収益153,334百万円（うち残存持分を支配喪失日現在の公正価値で再評価した利益44,822百万円）が含まれます。**basis 文は「有報が組み替えたと注記しているのは3行のみ」という事実の記述にとどめ、「当期利益は非継続事業を含む」と断定はしていません** — 有報がその行について明言していないためです。

この非対称が生む読み違いは実際に表に出ています。2025年3月期は**税引前利益88,219百万円 < 当期利益226,071百万円**です。異常値ではなく、継続事業のみの税引前利益と、範囲の違う当期利益を並べているためで、同期の `note` にそう書きました。

### `note` set on three years

- **2024年3月期**: 注2 の第14期＝この年であること、売上高は金属事業を含まない一方で**資産合計10,136,545百万円と従業員数43,683人はJX金属を子会社として含んだ時点の数値**であること。IFRS 第5号は貸借対照表の遡及的組み替えを求めないため、損益の行と残高の行で範囲がずれます。
- **2025年3月期**: 上場日2025年3月19日、売出し後の所有割合42.4％、支配喪失と持分法適用会社化、非継続事業からの当期利益229,569百万円とその内訳、資産合計と従業員数が減った理由、税引前利益 < 当期利益 の理由。
- **2026年3月期**: 金属事業が非継続事業ではなく持分法による投資利益として「その他」に入ること、在庫影響を除いた営業利益相当額4,744億円、油価と為替の期平均。

## 沿革 date format

`history.txt` は**日付がすべて各事象の直前にインラインで印字されています**（「2010年４月JXホールディングス株式会社設立により…」「2020年６月JXTGホールディングス株式会社がENEOSホールディングス株式会社に商号変更」「2025年３月JX金属株式会社の東京証券取引所プライム市場への新規上場に際し…」）。〔前史〕〔提出会社設立以降〕と、①新日本石油グループ②新日鉱グループ③東燃ゼネラルグループの3系譜も同じ形式で、**年セルが事象と分離しているブロックはありません**。沿革はそれ単体で健全で、第二のソースは不要でした。

3系譜ある沿革なので、history は8項目を「現在の会社を説明するのに要る転換点」に絞りました: 1888（新日本石油グループの起点）、1905（新日鉱グループの起点＝金属の起点）、2010（提出会社設立・上場）、2017（東燃ゼネラル統合）、2020（ENEOS への商号変更）、2024（セグメントごとの事業会社への分割）、2025（JX金属の上場と連結除外）、2026（Chevron案件）。東燃ゼネラルグループの前史（1893年の米国ソコニー日本支店開設など）は2017年の項の description に入れ、独立の項目にはしていません。

## Gaps and judgement calls

1. **`revenueBasis` / `netIncomeBasis` を全5年に設定** — この4社のなかで唯一の perimeter change です。理由と、`netIncomeBasis` が `revenueBasis` と違う理由、basis 文を断定にしなかった理由まで上に書きました。
2. **pack の修正再表示チェックが、この組み替えを検出できません。** 28行一致は「直前の有報と一致」でしかなく、組み替えは前期の有報で既に行われています。**「一致」を「範囲が同じ」と読んではいけない例で、有報の注記を読まなければ完全に見落としていました。** pack 側で改善できるとすれば、「非継続事業」「組み替え」「遡及」といった語が 注記や `indicators.txt` の注にあるときに警告を出すことです。
3. **2024年3月期・2025年3月期は損益の行と残高の行で範囲がずれます。** 売上高・税引前利益は継続事業のみ、資産合計・従業員数はその時点の実態（2024年3月期はJX金属を含み、2025年3月期は含まない）。IFRS 第5号が貸借対照表の組み替えを求めないためで、`note` に書きました。エントリのスキーマは basis フィールドを revenue と netIncome にしか持たないので、総資産・純資産・従業員数についてはこの `note` が唯一の断り書きです。
4. **2025年3月期は 税引前利益 < 当期利益** です。データの誤りではなく範囲の違いで、`note` に理由を書きました。
5. **`profit` に 営業利益 ではなく 税引前利益 を採った判断** — 上に理由。この表は両方を印字しているので、選択が必要でした。
6. **その他が2番目の売上高・2番目の利益でありながら最後** — 上に理由。この会社ではこの規則の影響が最も大きいので、その他の description 本文にも明記しました。
7. **金属事業の扱い**: 独立したセグメントは存在しないため、その他の区分のなかで (a) グループに残った非鉄金属製品・機能材料・薄膜材料・リサイクルと (b) JX金属の持分法による投資利益、の二つとして記述しました。JX金属自体の事業内容はこの有報が詳しく書いていないため、書いていません（同社は自ら有価証券報告書を提出する別会社です）。
8. **会社自身の優越的表現は帰属付きで使いました。** 「国内最大の燃料油販売シェアを有する石油精製販売事業」は有報の記述なので「会社は…としています」の形にしました。再生可能エネルギーについて有報が使っている「業界のリーディングカンパニーとしての地位を確立すべく」は、`description` で禁じられている語を含むため、「洋上風力を含めた再生可能エネルギー全般を幅広くカバーすることを目指すとしています」と言い換えました（内容は同じ文の前半そのままです）。
9. **`industries`: `energy`（primary）と `chemicals`。** 機能材が報告セグメントであることが `chemicals` の根拠です。その他にアスファルト舗装・土木工事・建築工事がありますが報告セグメントではないので `construction` は付けていません。
10. **大阪証券取引所は `listings` に入れていません** — 沿革の2010年4月に上場先として記載がありますが、現在の表紙の「上場金融商品取引所名」は東京（プライム）と名古屋（プレミア）の2つだけです。
11. **Nothing is null.** 6シリーズすべてが5年分そろっています。`status` は `published` ですが、この会社は**範囲の断絶があるので、チャートを読む人が basis フィールドと `note` を見る必要があります**。
12. `name` は「ENEOSホールディングス」、`shortNameEn` は「ENEOS」（英訳名 ENEOS Holdings, Inc. から法人格・Holdings を落としたもの）。
