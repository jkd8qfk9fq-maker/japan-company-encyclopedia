- `accountingStandard`: 全年度 `ifrs`。表紙 DEI「会計基準」= IFRS、かつ 主要な経営指標等の推移の注1が

- **ラベルの訂正（draft-entry.json のバグ）**: draft の `netIncomeLabel` は
  `当期利益又は当期損失（△）：親会社の所有者に帰属（IFRS）`（XBRL taxonomy のラベル）だった。
  `indicators.txt` の印字は **「親会社の所有者に帰属する当期純利益（△は純損失）」**。
  protocol と brief の指示（ラベルは taxonomy でなく印字）どおり印字に直した。
  他の4ラベル（`売上高`／`税引前利益（△は損失）`／`総資産額`／`親会社の所有者に帰属する持分`）は
  draft のまま印字と一致していた。総資産は「総資産」ではなく **「総資産額」** と印字される。

  行が印字されておらず、フォールバックのラベルがそのまま正しい。ラベルがそれを示している。
- 純資産の候補として 親会社の所有者に帰属する当期包括利益 の行が表に並ぶが、これは純利益の行では
  ないので使っていない（`netIncome` は 親会社の所有者に帰属する当期純利益 の行）。

### `revenueBasis` / `netIncomeBasis` — 設定しなかった（判断）

理由: 5年間で **集計範囲（perimeter）の表示が変わっていない**。
- 会社は期間中に事業の売却・撤退を複数行っているが（2021年 北米建築用ガラス事業を Cardinal Glass
  Industries 社へ譲渡、2023年 艾杰旭特種玻璃（大連）有限公司の全株式譲渡、2024年2月 ロシアの
  建築用・自動車用ガラス事業を譲渡し同国から撤退）、いずれも **非継続事業として区分表示されておらず**、
  過去年度の遡及的な組み替えも行われていない。
- 前期有報との重複年度の照合は 24行すべて一致（`restatementCheck` に差異ゼロ）。修正再表示はない。
- したがって全年度が同一の測定範囲にあり、チャートを分断する必要がない。protocol の
  「Omit both when the scope is consistent」に該当。

### `note` — 2年度に付けた（判断）

- 2024年12月期: 税引前損失・当期純損失の理由（ロシア事業譲渡に伴う関係会社株式売却損、
  ライフサイエンス（バイオ医薬品CDMO）に係る減損損失。非金融資産の減損損失124,975百万円）。
  売上高と営業利益は前年度から増加しているため、純損失だけを見た誤読を防ぐ1文。出典は MD&A。
- 2025年12月期: 税引前利益が前期比1,748億円増となったのは上記の一過性損失の剥落であること。
  これは測定方法の変更ではなく **一過性の費用の有無** による年度比較の注意点なので `note` が適切で、
  `revenueBasis`/`netIncomeBasis` の案件ではない。

## Gaps and judgement calls

1. **2026年の修正後の財務KPIの数値は書いていない**。経営方針 (2)① は「今般、2026年の財務KPIを以下の
   とおりとしました」としたうえで表を置いているが、その表は evidence pack のテキストに落ちておらず
   （残っているのは脚注「*EBITDA＝営業利益＋減価償却費」「**2023-2025平均。CAPM（資本資産価格モデル）
   で算出」だけ）、修正後の数値が確認できない。したがって「当初の営業利益2,300億円から2回下方修正した」
   という確認できる事実とその理由のみを書き、修正後の値は書いていない。
2. **収益性指標は意図的に書いていない**。会社は ROCE / ROE / DOE / 配当を財務目標と株主還元方針に
   使っているが、これらは投資指標として entry に載せない対象なので、経営方針の当該記述は
   採らなかった（`businessModel` では事業ポートフォリオの方向性と設備投資方針だけを引いた）。
   このため会社の「対処すべき課題」の記述のうち収益性指標の部分は entry に反映されていない。
3. **顧客企業名は1社も書いていない**。研究開発活動に共同開発先として1社の名前が出てくるが、
   顧客・取引先として名指しする書き方は避け、製品名（ガラスアンテナ）も採らなかった。
   セグメント情報 (3) が「外部顧客への売上高が10％を超える単一の相手先がない」としており、
   `customers` は産業・分野のレベルで記述した。
4. **`industries` の選択**: primary は `chemicals`（東証の業種分類は「ガラス・土石製品」で、
   INDUSTRY_IDS に該当する id がないため、化学品が売上高・利益で最大の報告セグメントであることを
   根拠に chemicals を主とした）。副として建築用板ガラスから `construction`、自動車用ガラスから
   `automotive`、半導体関連部材から `semiconductors` を付けた。ライフサイエンスは医薬品の
   開発製造受託であり創薬・販売ではないため `pharmaceuticals` は付けていない（判断）。
5. **`name` / `shortNameEn`**: 表紙の商号は全角の「ＡＧＣ株式会社」。表示名 `name` は半角の `AGC`、
   `officialName` は表紙どおりの全角、`nameEn` は表紙の英訳名 `AGC Inc.`、`shortNameEn` は
   法人格を落とした `AGC`。
6. **`listings`**: 表紙「上場金融商品取引所名」は東京証券取引所（プライム市場）の1件のみ。
   海外上場の記載はない。
7. **セグメント利益の呼称**: AGC のセグメント損益は「セグメント利益又は損失（営業利益）」であり、
   コア営業利益のような調整後指標ではない。entry でも「セグメント利益（営業利益）」と書いた。
8. **修正再表示**: なし。`restatementCheck` は revenue / netIncome / profit / totalAssets /
   netAssets / employees の6系列それぞれ4行、合計24行を前期有報と照合して差異ゼロ。

   判断に影響しない。）
