### なぜ違うか（有報が自分で説明している）

主要な経営指標等の推移 注2：

> 当社は、第21期において、当社の連結子会社であった田辺三菱製薬㈱（現　田辺ファーマ㈱）の全株式及び関連資産を吸収分割により譲渡したことに伴い、**同社及びその子会社等の事業を非継続事業に分類し、第20期についても組み替えて表示しております。したがって、第20期及び第21期の売上収益及び税引前利益は、継続事業の金額を表示しております。**

注記「７．非継続事業」：

> 2025年６月25日、当社の定時株主総会において、連結子会社であった田辺三菱製薬㈱の全株式及び関連資産を Bain Capital Private Equity, LP が投資助言を行う投資ファンドが間接的に株式を保有する特別目的会社である㈱BCJ-94に承継させる吸収分割契約が承認可決され、**2025年７月１日に当該取引は完了しました。**これに伴い、当連結会計年度において同社及びその子会社等の事業を非継続事業に分類するとともに、**前連結会計年度についても再表示**し、当該非継続事業を区分して表示しております。

**結論：誤りの修正（修正再表示）ではなく、IFRS第5号に基づく非継続事業への分類と、それに伴う前連結会計年度の組替え（再表示）である。** 原因は「三菱ケミカルグループの医薬事業＝田辺三菱製薬の連結除外」で、リクラシフィケーションであって restatement ではない。

### `revenueBasis` / `netIncomeBasis` — **両方を5年すべてに設定した**（判断）

これは富士通・セブン＆アイと同じケースである。

- **売上収益**：2022〜2024年3月期は医薬事業を含むグループ全体、2025・2026年3月期は継続事業のみ。**同じ列に並べると2つの違う範囲を比べることになる。**
- **純利益**：5年とも「親会社の所有者に帰属する当期利益」で、非継続事業を含む総額という点では一貫している。ただし2025・2026年3月期は有報が継続事業と非継続事業を区分して表示しており、とりわけ2026年3月期は1,286億円の売却益が入っている。

したがって設定値は次のとおり。純利益の基準が「同じだが区分表示の有無が違う」ことを、言葉でそのまま書き分けている。

| fiscalYear | `revenueBasis` | `netIncomeBasis` |
|---|---|---|
| 2022年3月期 | 医薬事業（田辺三菱製薬）を含むグループ全体 | グループ全体（非継続事業の区分なし） |
| 2023年3月期 | 同上 | 同上 |
| 2024年3月期 | 同上 | 同上 |
| 2025年3月期 | 継続事業のみ（田辺三菱製薬の事業を非継続事業として除く） | 継続事業と非継続事業（田辺三菱製薬の事業）の合計 |
| 2026年3月期 | 同上 | 同上 |

`profit`（税引前利益）にも同じ断層があるが、スキーマに `profitBasis` がないため、2025年3月期と2026年3月期の `note` に「売上収益と税引前利益は継続事業の金額」と明記して補っている。

`_会計基準がそろわない項目` フラグは draft-entry.json に**付いていない**。

## Gaps and judgement calls

1. **evidence pack と `verify-financials.mjs` の「修正再表示なし」は、この会社では正しくない。** 比較行数が0なのに「一致」と表示される。実差は第20期の売上収益△4,598億円・税引前利益△514億円。上の「★」節に実測値を記載した。**ツール側の改善が必要**（データ側の問題ではないので、指示どおりデータは一切曲げていない）。
2. **`revenueBasis` / `netIncomeBasis` を5年すべてに設定した。** 理由と各年の文言は上記のとおり。この判断がこのエントリーの中心。
3. **税引前利益にも同じ断層があるが `profitBasis` がスキーマにない。** 2025年・2026年3月期の `note` で補った。将来 `profitBasis` を足すなら、このエントリーが最初の利用者になる。
4. **非継続事業の売上収益と組替え前の売上収益の差12,316百万円を説明できない。** 内部取引の消去とみられるが有報が明示していないため、エントリーには書かず、両有報の印字値だけを `note` に並べた。
5. **history が合弁契約に偏っている。** 会社の物語として重要な2017年の三菱ケミカル㈱発足、2022年の商号変更、大陽日酸の子会社化は、年を有報内で裏付けられなかったため落とした。公式の沿革ページを追加ソースとして当たれば補える穴である。
6. **`industries` に素材・産業ガスのちょうどよい id がない。** `chemicals` を primary とし、スペシャリティマテリアルズの半導体・エレクトロニクス材料に対して `semiconductors` を副次に付けた。産業ガス（外部収益で最大のセグメント）に対応する id は `INDUSTRY_IDS` に存在しない。
7. **「その他」を top-level business に入れた。** 有報が「主なものはエンジニアリング、運送及び倉庫業です」と中身を説明しているため。
8. **売上収益の順位と利益の順位が一致している（産業ガスが両方で最大）** ので、旭化成のような食い違いの注記は不要だった。ただしベーシックマテリアルズ＆ポリマーズとMMA＆デリバティブズは2026年3月期にいずれもセグメント損益が損失で、これは各事業の description に書いた。
9. **投資指標は一切転記していない。** 主要な経営指標等の推移には1株当たり親会社所有者帰属持分・基本的1株当たり当期利益・親会社所有者帰属持分利益率・株価収益率が並ぶが、どれもエントリーに入れていない。
10. **2026年4月以降の事象**（コーポレートベンチャーキャピタル事業の三菱ケミカル㈱への移管、大陽日酸ほかの商号変更、日本サウディメタクリレート合同会社の吸収合併）は、当期末後のため history には入れず、事実として必要な箇所（子会社名の注記）でのみ触れた。
