### `profit` に 税引前利益 を採った判断

**この filer は5年表に「営業利益」と「税引前利益」の両方を印字しています**（印字順：売上高 → 営業利益 → 税引前利益 → 親会社の所有者に帰属する純利益）。営業利益は 2022年3月期 965,553／2023年3月期 1,060,168／2024年3月期 876,068／2025年3月期 989,016／2026年3月期 1,042,576 百万円で、XBRL にもタグ付けされています。

研究プロトコルは `profit` を「売上と純利益の間の行」と定義しつつ、「**それは意図的に営業利益ではない**（IFRS では税引前利益）」と明記しているため、**税引前利益を採用しました**。`draft-entry.json` の `profitLabel: "税引前利益"` は印字どおりで正しく、そのまま使っています。営業利益は本文に載せる価値があるため、`businessModel` の profit ステップで数値とともに述べています。

### revenueBasis / netIncomeBasis / note の判断

- **`revenueBasis` / `netIncomeBasis` は設定しない。** 5年間で売上高・純利益の対象範囲が遡って組み替えられたという記載はありません。期中の子会社化（LINE MAN、Cubic Telecom など）は支配獲得日以降の取込みで、過去年度に遡って表示し直されてはいません。PayPay銀行のセグメント移管も**セグメント間の区分の移動**であり、連結の売上高・純利益には影響しません（`segments.txt`「2025年３月31日に終了した１年間の数値を遡及修正しています」はセグメント情報についての記述）。
- **`note` は2年度に付した（いずれも測定方法・一時的要因で、範囲の変更ではない）**：
  - 2022年3月期：`indicators.txt`（注１）「共通支配下の取引として取得した子会社については、第37期より、非支配株主が存在する中で行われた共通支配下の取引について、取得法に基づいて会計処理する方法に変更し、当該会計処理を遡及適用しています。そのため、第36期の連結経営指標は、遡及修正後の数値を記載しています」。**測定方法の変更**であり、第36期＝2022年3月期のみが遡及修正されているため、この年度に note を置きました。
  - 2026年3月期：`segments.txt`（注２）「「メディア・EC」の「セグメント利益」にはLINE MAN CORPORATION PTE. LTD.の子会社化に伴う段階取得に係る差益44,377百万円が含まれています」。営業利益・税引前利益にも含まれる一時的要因であり、この年度の利益の伸びを読むのに必要と判断しました。
- `indicators.txt`（注２）の株式分割（2024年10月1日、普通株式1株につき10株）は1株当たり情報にのみ関わるため entry には書いていません（本プロジェクトの禁止語に該当する領域）。

## 沿革の形式

`history.txt` は **「年月｜概要」の表で、各行の日付が事象の直前にインラインで印字される形式**（「1986年12月日本国有鉄道の分割民営化に伴い…設立」「2006年10月ソフトバンクモバイル㈱に商号変更。ブランド名を「ソフトバンク」に変更」）。年セルが事象と分離して出力される形式ではないため、**沿革だけで年と事象の対応が確定でき、フィリング内の第二のソースは必要ありませんでした。**

採用した8件は、会社の姿が変わった節目に絞ったものです。沿革には（旧）日本テレコム、（旧）ボーダフォンの沿革が注記として別掲されていますが、当社そのものの沿革ではないため history には入れず、2001年・2006年の `description` で当社の商号変更として述べています。

## Gaps and judgement calls

1. **「その他」を事業として立てていません。** `segments.txt` は「上記の報告セグメントに含まれない情報は、「その他」に集約されています」としており、その他は報告セグメントではありません（`business.txt` f. にはデジタルメディア・デジタルコンテンツの企画・制作という説明があります）。トップレベルは報告セグメントとするプロトコルに従い、5区分にしました。外部顧客への売上高128,586百万円は上表に記録しています。
2. **`children` を置いたのはコンシューマとメディア・ECの2つだけです。** この2つは有報自身が (a)(b)(c) および メディア／コマース／戦略 と下位区分を明示しているためです。エンタープライズ・ディストリビューション・ファイナンスは文章の中で分野を並べるだけで下位区分を立てていないため、フラットにしました。
3. **`industries` は telecommunications のみ（primary）にしました。** メディア・ECの外部顧客への売上高1,641,041百万円は連結の約23%で、`it` や `media` を副次業界として加える余地はありますが、有報が当社を「通信・IT企業グループ」と述べているだけで業界区分を示していないため、主業の1つに絞りました。登録時に再検討の余地があります。
4. **2026年3月期の売上高増加の内訳（既存事業の伸びと子会社化の寄与の区別）は書いていません。** 有報のセグメント情報には子会社化の寄与額の内訳がなく、推測になるためです。LINE MANの段階取得差益44,377百万円のみ、金額が明記されているので note にしました。
5. **PayPay銀行㈱のセグメント移管を業種説明に反映していますが、財務の note にはしていません。** `segments.txt`「2025年４月11日付のグループ内再編に伴い経営管理区分を見直し、PayPay銀行㈱については、従来の「メディア・EC」から「ファイナンス」へ移管しています。これに伴い、2025年３月31日に終了した１年間の数値を遡及修正しています」。上表のセグメント数値は遡及修正後のものであり、連結の5年表には影響しません。
6. **2026年4月1日のSBテクノロジー㈱吸収合併は history に入れていません。** `history.txt` 最終行と `business.txt`（注６）にありますが、当年度末後の出来事であり、事業構造の説明としては細かいと判断しました。
7. **顧客名を書いていません。** 有報は「売上高の10％を超える単一の外部顧客はない」と述べており、顧客を名指ししていないため、`customers` はエンタープライズの「法人」と businessModel の一般的な記述に留めました。
8. **決算短信・統合報告書・会社サイトは参照していません。** 有報XBRLと印字が全系列で一致したため。
9. `relatedCompanies` は `[]`。親会社ソフトバンクグループ㈱は本エンサイクロペディアに掲載されておらず、KDDI・NTTとの関係も別パスの調査対象です。
