- **ラベルの訂正（draft-entry.json のバグ）**: draft の `profitLabel` は `経常利益` だったが、
  `indicators.txt` の印字は **「経常利益又は経常損失（△）」**（第35期が経常損失であるため会社が

  これは JR東日本の pack にもあった同じ種類の誤りで、決算が赤字の年を含む5年表では

### `revenueBasis` / `netIncomeBasis` — 設定しなかった（判断）

理由: 5年間で **集計範囲（perimeter）が変わっていない**。
- 非継続事業として区分表示された事業はなく、遡及的な組み替え（retroactive presentation）を伴う
  取得・売却の記載もない。連結子会社数は第35期29社→第39期27社と2社減っているが（注1）、
  過去年度を組み替える性質の変更としては記載されていない。持分法適用会社数は5年間2社で一定。
- 前期有報との重複年度の照合は 6系列×4行 = 24行すべて一致（`restatementCheck` に差異ゼロ）。
  修正再表示はない。
- したがって全年度が同一の測定範囲にあり、チャートを分断する理由がない。
  protocol の「Omit both when the scope is consistent」に該当。

### `note` — 2026年3月期のみ（判断）

当年度の増収の中身（東海道新幹線の輸送人キロが前年度比10.2％増で運輸収入が11.1％増、
全ての事業区分で増収）と、営業収益の伸び9.5％に対し営業費の伸びが4.2％にとどまったことを
1文で置いた（MD&A (1)①②）。増益幅が増収幅を上回った理由を読者が誤解しないための1文で、
測定方法の変更ではないので `revenueBasis`/`netIncomeBasis` の案件ではない。

**2022年3月期の経常損失67,299百万円・当期純損失51,928百万円については `note` を置いていない** —
理由は下の Gaps 1 参照。

### 沿革（`history`）
**形式の確認 — ほぼインライン、1か所だけ月が分離**。`history.txt` は年月が各事項の直前に
インラインで印字される形式（`1987年４月東海旅客鉄道株式会社設立`、`1991年10月東海道新幹線鉄道施設を譲受け`）
で、**沿革だけで日付が確定できる**。例外は1か所:

```
2013年２月８月東海道新幹線「のぞみ」にＮ700Ａ車両を投入山梨リニア実験線の42.8kmへの延伸と設備更新が完了し、走行試験再開
```

## Gaps and judgement calls

1. **2022年3月期の経常損失67,299百万円・当期純損失51,928百万円の理由は書いていない**。
   この有報の MD&A は当連結会計年度（2026年3月期）のみを分析しており、第35期の損失の原因を
   述べた記述がパック内に見つからなかった。原因を書けば記憶からの補完になるので `note` を置かず、
   数値だけを載せた。第35期の有報を読めば埋まる欠落である。
2. **2026年の財務目標にあたる数値目標は entry に書いていない**。第2-1 は「業務改革」と
   「収益の拡大」という戦略の柱と中央新幹線の方針を述べるが、JR東海はこの有報で
   中期経営計画としての数値目標を提示していない。存在しないものを書かないという判断で、
   投資計画額（中央新幹線の総工事費見通し）と支出実績のみを載せた。
3. **株式分割（注2）は entry に反映していない**。2023年10月1日を効力発生日として普通株式1株につき
   5株の株式分割が行われ、注2 は1株当たり指標を第35期期首に分割があったものとして算定したと

4. **収益性指標・株主還元の指標は意図的に書いていない**。有報は自己資本利益率、1株当たり当期純利益、
   株価収益率、自己資本比率、配当政策を記載しているが、前3つは投資指標として掲載しない対象。
   中央新幹線の資金計画を説明するうえで会社自身が使う「健全経営と安定配当を堅持」という
   表現のみ、方針の引用として残した（金額・比率は書いていない）。
5. **運輸業の children は連結セグメントの内訳ではない**。新幹線／在来線／バス事業という分け方のうち、
