### 検証の結果（重要・未解決）

```
node scripts/research/verify-financials.mjs chugai-pharmaceutical   → exit 1
npm run content:validate-file -- src/data/companies/chugai-pharmaceutical.json → exit 0
```

`verify-financials.mjs` の出力:

- 「10 件の数値を有報XBRLと照合」「利益・総資産・純資産・従業員数: 20 件を照合」
  — **数値の不一致は0件**。全30件がXBRLのタグ値と一致している。
- 不一致として報告された5件は**すべて同一のラベル判定**:
  「2021年12月期 純利益: ラベル『当社の株主に帰属する当期利益』に親会社帰属の明示がありません」（他4年度も同文）

原因はスクリプト側にある。`scripts/research/verify-financials.mjs` の

```js
const PARENT_ATTRIBUTION = /(親会社株主に帰属|親会社の所有者に帰属|当社株主に帰属|当社の所有者に帰属|当社に帰属)/;
```

に、中外製薬が印字する **「当社の株主に帰属」**（「当社」と「株主」の間に「の」が入る形）の異体がない。

- `当社株主に帰属`（の なし）… 一致しない
- `当社の所有者に帰属`（株主 ではなく 所有者）… 一致しない
- `当社に帰属`（連続していないため）… 一致しない

**この有報で選べるラベルはどちらも通らない**ことを確認した:

| 試したラベル | `indicators.txt` に存在 | PARENT_ATTRIBUTION | 結果 |
|---|---|---|---|
| `当社の株主に帰属する当期利益`（印字・帰属先明示） | ○ | × | exit 1（5件） |
| `当期利益`（XBRLタグのラベル） | ○ | × | exit 1（5件） |

したがってこれは**データの問題ではなくツールの問題**であり、指示に従い数値やラベルを曲げずに停止した。
既存55社の `netIncomeLabel` を全件確認したが「当社の株主に帰属…」の前例はなく、この会社が初出である。

**提案（リードの判断事項。このパスでは実行していない）**: 正規表現に `当社の株主に帰属` を追加する
（`scripts/research/verify-financials.mjs` は「自分の3ファイル以外を編集しない」対象に含まれるため触っていない）。
この追加はチェックの厳しさを落とさない——帰属先が明示されたラベルだけを通すという意図はそのまま満たされ、
むしろ「当期利益」という帰属先の書かれていないタグラベルを退ける効果は保たれる。

### 沿革の日付の形式について

`history.txt` は「1925年３月上野十蔵、中外新薬商会を創業」「2002年10月エフ・ホフマン・ラ・ロシュ…」のように、
**日付が各事象の直前にインラインで印字**されている（年の途中で月だけが続く箇所——1971年２月／３月、
1997年３月／12月など——も、直前の年に続く形で読める）。年セルが事象から分離する形式ではないため
日付のずれは起こらず、沿革だけで日付は成立している。裏取りの追加ソースは不要と判断した。

## Gaps and judgement calls

1. **`revenueBasis` / `netIncomeBasis` を全5年度に設定した。** 根拠は指標表の注記3:
   「売上収益につきまして、**2023年度より当該項目から製品譲渡に係る収益を除外しております**。また、
   製品譲渡に係る収益に関連するキャッシュ・フローは、従来の『営業活動によるキャッシュ・フロー』から、
   『投資活動によるキャッシュ・フロー』へ変更しております。**これに伴い2022年度の実績も同様に組替えて
   表示しております**。」
   組替えは2022年度までしか遡っておらず、**2021年12月期だけが製品譲渡に係る収益を含んだままの表示**である。
   つまり売上収益が指す範囲が5年間で変わっており、2021年の列と2022年以降の列は同じものを測っていない。
   プロトコルの「what revenue covers changes across the five years」に該当するため、グラフを分断する
   （`revenueBasis` を全年度に置くと `netIncomeBasis` も全年度に必要になる）。
   - `revenueBasis`: 2021年=「製品譲渡に係る収益を含む（2023年度からの組替え前）」、
     2022年=「製品譲渡に係る収益を除く（2023年度の変更に伴い組替え）」、2023〜2025年=「製品譲渡に係る収益を除く」。
   - `netIncomeBasis`: 有報は当期利益への影響を記載していないため、**金額への影響は主張していない**。
     年度が組替えの前か後かだけを述べる表現（「売上収益の組替え前／後の表示にもとづく」）にした。
2. **`note` は2021年12月期にのみ設定した。** 上記の組替えを知らずに2021年と2022年を比べると
   読み違えるため。注記3の記述の範囲内に留め、影響額（製品譲渡に係る収益がいくらだったか）は
   有報が示していないので書いていない。
3. **`verify-financials.mjs` が exit 1**（上記「検証の結果」）。**数値の不一致は0件**、原因は
   スクリプトの親会社帰属ラベルの正規表現に「当社の株主に帰属」の異体がないこと。
   指示に従い、通すためにラベルや数値を変えることはしていない。
   `npm run content:validate-file` は exit 0。
4. **決算短信によるクロスチェックは行っていない。** パックに含まれず、XBRLタグ値と印字が一致しているため。
5. Core実績（Core営業利益、Core当期利益など）は会社が非経常事項を調整した独自指標であり、
   財務テーブルの数値とは別物なので、ビジネスモデルの説明で「会社が開示しているCore実績」と
