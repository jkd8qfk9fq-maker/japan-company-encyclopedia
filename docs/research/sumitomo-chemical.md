### revenueBasis / netIncomeBasis / note の判断

**`revenueBasis` / `netIncomeBasis` は設定しなかった。`note` を2年度（2025年3月期・2026年3月期）に置いた。**

この会社は5年のあいだに実際に事業を手放している。確認した事実は次のとおり。

- 注記37(3)「子会社に対する支配の喪失」：**前連結会計年度（2025年3月期）**に連結子会社であった
  **日本メジフィジックス㈱の全株式**を譲渡し、**住友ケミカルエンジニアリング㈱の一部株式**を譲渡。
  **当連結会計年度（2026年3月期）**に住友ファーマ社が連結子会社であったSMP準備㈱の一部株式を譲渡。
- 第2-4：前年度の事業撤退に伴うアルミニウム等の出荷減少、当年度の事業譲渡に伴う合成樹脂の出荷減少、
  「その他」は放射性診断薬事業等の売却により **当社の連結から除外された**。
- 経営方針：2025年10月よりペトロ・ラービグ社への持分比率を15％へ引き下げ（同社は**持分法適用会社**であり連結子会社
  ではないため、連結売上収益の範囲そのものは動かない）。

それでも basis を置かなかった理由：

1. **この有報は非継続事業（IFRS第5号）としての表示を行っていない。**`sections.json` 全文を検索した結果、
   「非継続事業」の語は注記3（重要性がある会計方針）の企業結合に関する定型文の中にしか現れず、
   連結損益計算書にも5年表にも継続事業／非継続事業の区分はない。売上収益は5年とも単一の系列である。
2. **過年度の数値は一切組み替えられていない。**`brief.md` の修正再表示チェックは6項目すべてで突き合わせ可能な行があり
   （8行）差異ゼロ、`verify-financials.mjs` も「前期有報との比較: 24行一致（修正再表示なし）」。
   非継続事業への振替や遡及表示があれば、ここに差異が出る。
3. すなわち各年度の数値は、その年の連結範囲を、同一の IFRS 表示基準で測ったものである。売却はいずれも
   **支配喪失日をもって将来に向かって**処理されており、年度間で「測り方」が変わってはいない。

basis を置くとページはチャートを分断し「これらの年の列は異なる範囲を測っている」と述べる。ここで起きているのは
表示基準の変更ではなく、会社自身が報告した実際の減収であるため、分断は読者に誤った印象を与えると判断した。
代わりに、読者が年度を正しく読むために必要な事実を `note` として2年度に置いた（2025年3月期＝放射性診断薬事業等の
連結除外と過年度が組み替えられていないこと、2026年3月期＝会社自身が挙げる2,778億円減収の4つの理由）。

**この判断は保守的ではない側に倒していない点を明記する**：連結範囲の変動そのものは事実として note に書き、
「過去の年度の数値は組み替えられていません」と読者に直接伝えている。

## Gaps and judgement calls

1. **沿革の形式**：`history.txt` は「1925年６月株式会社住友肥料製造所として独立新発足(現在の愛媛工場)」のように、
   **年月が各事象の直前にインラインで印字される形式**だった。年セルが事象と分離する形式ではないため、
   **沿革だけで日付が確定でき、フィリング内の第二のソースは不要**と判断した。
2. **1913年の history 項目**：沿革の本文冒頭が「当社は1913年９月、住友総本店が…肥料製造所を開設したのを事業の始めとし、
   1925年６月、株式会社住友肥料製造所として独立しました」と述べているため、`year` を 1913 とし、
   1925年の独立を `description` に含めた。年表部分の最初の行は1925年である点も本文に書いた。
3. **2024年3月期（第143期）の大きな損失に `note` を置いていない**：税引前△462,792百万円、親会社帰属△311,838百万円と
   5年で唯一の大幅赤字だが、**この有報（第145期）は当年度と前年度の分析しか載せておらず、2024年3月期の損失理由を
   述べていない**。理由を推測で書くことはできないため note を置かず、ここに欠落として記録する。第143期の有報を
   読めば理由が書けるが、エビデンスパックに含まれておらず、今回は取得していない。
4. **basis を置かなかった判断**：上記「revenueBasis / netIncomeBasis / note の判断」に根拠を詳述。
   連結範囲の変動は実在するが、非継続事業表示も過年度の組替えも行われていない。
