### draft-entry.json の誤りを1件修正した

`2026年3月期` の `employees` が **67,526** になっていたが、これは **IFRS の表の従業員数**である。
同じ年の**日本基準の表の従業員数は 51,717 人**。IFRS の表の注3が
「移行日および第23期の従業員数は、日本基準による連結範囲に基づくものです」と述べ、
従業員の状況（注2）も「IFRSへの移行に伴う連結範囲の見直しにより、新たに連結対象となった会社の
従業員数を含めたこと等により、従業員数は前連結会計年度末と比べ増加しています」と述べているので、
67,526 は **IFRS の連結範囲**の人数である。他の5項目（経常収益・経常利益・純利益・総資産額・純資産額）が
すべて日本基準の連結範囲である行に、連結範囲の違う人数を混ぜると 51,436 → 67,526 の
見かけ上 31% の増加が出てしまう。**51,717 に直した**。67,526 は 2026年3月期の note と
ビジネスモデルの「会社」ステップに、IFRS の数値として明記している。

### 基準（revenueBasis / netIncomeBasis）の判断 → **設定しない**

- 格納した5年間はすべて**日本基準・日本基準の連結範囲**で、集計範囲（perimeter）は5年を通じて一貫している。
  よって perimeter change ではなく、`revenueBasis` / `netIncomeBasis` は置かない。
- 一方、**測定方法（measurement method）の変更**は2つあるので、`note` で記載した。
  1. **2022年3月期**: 有報注1「IFRSを適用している海外連結子会社において、IFRS第17号『保険契約』を
     第22期の期首から適用しています。当該会計基準は遡及適用され、第21期については遡及適用後の数値と
     なっています」。つまり第20期（2022年3月期）だけが遡及適用の対象外。
  2. **2025年3月期・2026年3月期**: 第24期から連結財務諸表がIFRSになった。両年度の note に
     IFRSの保険収益・税引前利益・親会社の所有者に帰属する当期利益・総資産額を併記し、
     2026年3月期には従業員数67,526人と、日本基準の数値が監査を受けていない旨（有報注5）も書いた。

`accountingStandard` は5年とも `jgaap`。表紙のDEI「会計基準」は IFRS だが、**格納している数値そのものが
日本基準の行**なので、行の属性としては日本基準が正しい。IFRS への移行は note と status で明示している。

## Gaps and judgement calls

1. **5年間の表に日本基準の行を採った（最大の判断）。** 有報は第24期からIFRSで連結財務諸表を作成しており、
   表紙のDEI「会計基準」も IFRS。しかし IFRS の主要な経営指標等は**移行日・第23期・第24期の実質2年分**しかなく、
   5年を同じ基準で並べることができない。一方、日本基準の表は第20期〜第24期の5年分が揃っている。
   さらに技術的な制約として、エビデンスパックが売上の候補として持っているXBRL要素は
   `jpcrp_cor:OrdinaryIncomeSummaryOfBusinessResults`（経常収益）**のみ**で、IFRS の保険収益は
   revenue の候補に入っていない（summary.json の figures.revenue を確認）。
   データを曲げたわけではなく、**有報自身が印字している5年間の表**をそのまま採っている。
   IFRS の数値は各年度の note とビジネスモデルに併記し、status にも書いた。
2. **2026年3月期の日本基準の数値は監査を受けていない**（有報 注5）。note に明記した。
3. **事業の系統図が取れなかった。** business.txt は「2026年3月31日現在の事業の系統図は以下のとおりです」と
   書いたあと図が続くが、XBRLのテキストには図が入らない。どのグループ会社がどのセグメントに属するかは
   「関係会社の状況」の「主要な事業の内容」欄（セグメント名が入っている）の範囲でのみ記載した。
   status の needs-attention に残した。
4. **沿革の日付の並びについて（タスクの指定事項）。** history.txt は**前半と後半で形式が違う**。
   - 2001年9月・2001年12月・2002年4月・2003年10月・2004年2月・2004年10月・2006年4月 の7件は、
     **年月が各イベントの直前にインラインで印字されている**。この範囲の沿革はそれ自体で成立している。
   - ところが末尾で `2007年7月 / 2008年7月 / 2014年10月 / 2022年4月` の**4つの年月セルが先にまとまって出力され、
     そのあとに4つのイベント文が続く**形になっている。年の列とイベントの列が分離した典型的なずれ方。
   - 有報の**他の箇所に、この4件を裏付ける第二の記述はない**。sections.json 全体を「ミレア」「ADR」で
     検索したが、該当箇所は 従業員の状況 の表に出てくる子会社名「東京海上ミレア少額短期保険株式会社」だけで、
     商号変更の年を述べた文はない。
   - **採った判断**: 沿革は年月の昇順に並ぶ2列の表であり、年月セル4件とイベント文4件が**同数**で、
     どちらも表の行順のまま出力されている。したがって i 番目の年月と i 番目のイベントが対応する、
     と機械的に読める。加えて末尾の 2022年4月 ↔「東京証券取引所の市場区分の見直しを受け…プライム市場に移行」は
     イベント文の内容そのものが年月を示しており、末尾の対応が確認できる。この対応でエントリーに採録した。
     対応関係が本文の第二記述で裏付けられたものではない点を、ここに明示しておく。
5. **ADR / ナスダック上場は `listings` に入れていない。** `exchange` の enum は tse/nse/fse/sse のみ。
   沿革（2002年4月にナスダックへADR上場、2007年7月に自主的に廃止し米国店頭市場へ移行）として記載した。
   現在の上場先は東京証券取引所プライム市場のみ（表紙）。
6. **経常収益の内訳は書けなかった。** 第24期の連結財務諸表はIFRSのみで、**日本基準の連結損益計算書が
   有報に載っていない**（sections.json の連結財務諸表はすべて IFRS）。したがって経常収益8,872,277百万円が
   何から成るかを有報から示せない。ビジネスモデルでは、その旨を明記したうえで、IFRSの保険収益の内訳と、
   日本基準の表が印字している正味収入保険料の5年推移を示した。三菱UFJフィナンシャル・グループのように
   経常収益の内訳を分解することはできていない。
7. **修正再表示（restatement）はなし。** パックの前期有報との比較は 22行一致・差異0件。
8. **短信との突き合わせは行っていない。** 有報が5年分の数値を自ら印字しており、不審な点がなかったため。
