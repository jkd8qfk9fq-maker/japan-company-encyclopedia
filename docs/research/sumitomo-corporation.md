### 修正再表示

`brief.md` の修正再表示チェック＝「前期有報と重複年度は全て一致（修正再表示なし・8行）」。「突き合わせられる行がない」ではなく、実際に8行比較して一致している。`verify-financials.mjs` も同じ結果を出力。

`brief.md` の注意として「前期の窓に 訂正有価証券報告書－第156期 がある」と出ているが、上記のとおり重複年度は8行一致しており、第158期有報の5年表の値と矛盾する数値はパック内に存在しない。パックには当該訂正報告書の本文が含まれていないため、**訂正報告書そのものは読んでいない**。本エントリーの数値はすべて第158期有報の自己申告値であり、これは有報の5年表を正とする本プロジェクトの方針どおり。

### revenueBasis / netIncomeBasis / note の判断

- **`revenueBasis` / `netIncomeBasis` は設定しない。** 5年間で収益の対象範囲（連結の範囲、非継続事業への振替など）が変わったという記載が有報に無く、`brief.md` の修正再表示チェックも重複年度8行一致。したがって perimeter change は確認できない。
- **`note` は3年度に付した（いずれも測定方法・内訳の説明で、範囲の変更ではない）**：
  - 2023年3月期：`indicators.txt` 注2「第156期よりIAS第12号「法人所得税」(2021年5月改訂)を適用しております。これに伴い、第155期について遡及適用後の数値を表示しております」。第155期＝2023年3月期。**測定方法の変更が1年度だけに遡及適用されている**ため、`note` で該当年度に明記した（BOTH basis は付けない）。
  - 2025年3月期：`segments.txt` 注5「資源グループにおいて、前期にマダガスカルニッケル事業に関する損失を計上しております。前期における当期利益(親会社の所有者に帰属)に対する影響額は、△18,859百万円であります」（「前期」＝2025年3月期）。2024年3月期→2025年3月期の純利益の動きを読むのに必要。
  - 2026年3月期：本人・代理人判定（注記3(13)）に基づく総額／純額認識の説明。「グロスまたはネット、いずれの方法で認識した場合でも、売上総利益及び当期利益に影響はありません」が有報の原文。商社の収益が製造業の売上高と同じ意味を持たないことを、この filer 自身の言葉で書いている。

## 沿革の形式

`history.txt` は **日付が各事象の直前にインラインで印字される形式**（「1944年11月株式会社住友ビルデイング…を合併して」「1969年10月大阪府に住商コンピューターサービス株式会社を設立」）。年セルが事象と分離して出力される形式ではないため、**沿革だけで年と事象の対応が確定でき、フィリング内の第二のソースは必要なかった**。

採用した8件は turning point に絞ったもので、年はすべて `history.txt` の印字どおり。1919年は「1919年12月24日登記 1919年12月30日…設立」と2つの日付が並ぶが、いずれも1919年であり年の判定に影響しない。

## Gaps and judgement calls

1. **`children` を置いていない。** 有報は各グループの構成を SBU 名（「エネルギー鋼管SBU」「リテイルSBU」など）で列挙しているが、これは社内の組織単位名であって「会社自身が説明する下位事業」の記述とは言い難い。既掲載の総合商社（三井物産）も本部名を description 内に書く扱いにしているため、9セグメントをフラットに置き、構成は description で述べた。
2. **2026年4月1日付の組織変更を反映していない。** `business.txt` 注2・注3 に、2026年4月1日付で「メディア・デジタルグループ」を「コミュニケーションサービスグループ」に改称し、その傘下のデジタルSBUを新設の「デジタル・AIグループ」へ移管したとある。研究プロトコルは「次の四半期報告書が新構造を既に使っている場合は新構造を採る」としているが、**パックに四半期報告書が含まれておらず、新構造でのセグメント区分（9→10になるのか等）も収益の対応も確認できない**。したがって有報が報告している9セグメントをそのまま採用した。確認でき次第、差し替えが必要になりうる。
3. **連結子会社数・持分法適用会社数を書いていない。** `affiliates.txt` は会社を列挙したうえで「(その他 ○社)」の形で省略しており、注1で「連結子会社が保有する持分法適用会社のうち…(2026年3月31日現在73社)については、上記会社数から除外しています」とあるため、合計社数を有報から機械的に確定できない。数えて書くと誤りになるので書かなかった。
4. **決算短信を参照していない。** 有報XBRLタグ値と `indicators.txt` の印字が全6系列・5年で一致したため、cross-check の必要が生じなかった。
5. **訂正有価証券報告書－第156期は読んでいない**（上記「修正再表示」参照）。パック外の文書であり、重複年度8行が一致しているため、本エントリーの数値には影響しない。
6. **1949年の上場と2026年のSCSK上場廃止を沿革に入れなかった。** いずれも `history.txt` にあるが、8件の turning point に収める判断として、事業のかたちを変えた出来事（1945 商事会社化／1950 土木建築分離／1962 商品本部制／1969 SCSK設立／1995 JCOM設立／2024 SBU再編）を優先した。
7. `relatedCompanies` は `[]`（別パスで調査する方針どおり）。
