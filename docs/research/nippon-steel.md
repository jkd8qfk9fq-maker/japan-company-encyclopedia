### Label check against `indicators.txt`

印字は「売上収益(百万円)／事業利益(百万円)／親会社の所有者に帰属する当期利益(百万円)／当期包括利益(百万円)／親会社の所有者に帰属する持分(百万円)／資産合計(百万円)…従業員数(人)」。draft-entry.json の6ラベルはすべて印字どおりで、**修正は不要だった**。

- `netIncome` は「親会社の所有者に帰属する当期利益」。真下に並ぶ「当期包括利益」（2026年3月期 358,595百万円）は採っていない。
- `netAssets` は「親会社の所有者に帰属する持分」。この表は資本合計（非支配持分を含む総額）の行を印字していないため、親会社持分がラベルどおりの値。
- `profit` は **事業利益**。経常利益でも税引前利益でもない、会社独自の指標で、XBRL でも拡張要素 `BusinessProfitIFRSKeyFinancialData` として付番されている。

### 事業利益とは（有報の定義そのまま）

主要な経営指標等の推移 注4：「事業利益とは、持続的な事業活動の成果を表し、当社グループの業績を継続的に比較・評価することに資する連結経営業績の代表的指標であり、**売上収益から売上原価、販売費及び一般管理費、並びにその他費用を控除し、持分法による投資利益及びその他収益を加えたもの**である。その他収益及びその他費用は、受取配当金、為替差損益、固定資産除却損等から構成されている。」

この定義を `businessModel.description` の末尾に書き下し、`flow` の `profit` ステップのタイトルも「事業利益」とした。読者が普通の営業利益・経常利益と取り違えないようにするため。セグメント利益も同じ事業利益ベースで測られている（事業セグメント注記 (2)）。

### `revenueBasis` / `netIncomeBasis` — 設定しなかった（判断）

2026年3月期に売上収益が8.70兆円→10.06兆円、資産合計が10.94兆円→14.66兆円、従業員数が113,845人→138,453人と大きく動いている。原因は USスチールの完全子会社化（取得日 2025年6月18日、企業結合注記）であり、**取得日以降を取り込む前向きの連結**である。過去4年は遡って修正されておらず（修正再表示なし）、非継続事業への振替も連結除外も起きていない。

したがって protocol の scope change の条件（非継続事業としての遡及修正、遡及適用される取得）に当たらないと判断し、`revenueBasis` / `netIncomeBasis` は**両方とも付けていない**。代わりに 2026年3月期の行に `note` を置き、(a) USスチール取得日以降の売上収益 1,933,070百万円が含まれること、(b) 過去の期は遡及修正されていないこと、(c) 会社自身が示す「取得日が期首だった場合」の売上収益 10,677,338百万円 を記載した（いずれも企業結合注記 (5)(6)）。

`_会計基準がそろわない項目` フラグは draft-entry.json に**付いていない**。

## History — 沿革の日付の裏取り

**既知のツールバグの影響あり。** `history.txt` の沿革表は年セルと事象セルがずれている箇所がある。実例：

```
1974年６月1984年４月エンジニアリング事業本部を設置新日本製鉄化学工業㈱及び日鐵化学工業㈱が合併し…
1988年４月 1989年６月日鐵コンピュータシステム㈱、…統合し…変更 ライフサービス事業部をエンジニアリング事業本部に編入
```

年が2つ並んだあとに事象が2つ続く形で、どちらの年がどちらの事象に対応するか表からは確定できない。**この種の箇所からは1件も採用していない**（1974/1984、1988/1989、1984年7月〜1999年4月の事業部設置・廃止の系列はすべて不採用）。

## Gaps and judgement calls

1. **`industries` に鉄鋼・素材の id がない。** `INDUSTRY_IDS` は automotive/semiconductors/electronics/it/finance/trading/food/retail/real-estate/construction/chemicals/pharmaceuticals/transportation/energy/telecommunications/media/entertainment の17種で、鉄鋼または素材にあたる id が存在しない。素材のバケットとして既存エントリーが使っている `chemicals` を primary にし、エンジニアリング事業を `construction`、システムソリューション事業を `it` として副次に置いた。**鉄鋼メーカーを「化学」に分類しているのは taxonomy 側の穴であり、`materials` または `steel` の id 追加を検討されたい**（types は編集しない指示のため触っていない）。
2. **`revenueBasis` / `netIncomeBasis` は付けていない。** 理由は上記「Financials」節のとおり。USスチール連結は前向きの取得であり遡及修正がない。読者への注意喚起は 2026年3月期の `note` で行っている。
3. **顧客名。** 「主要な顧客に対する売上収益」が10%超なしで省略されているため、販売先としての顧客リストは有報にない。`businessModel.customers` は研究開発活動が採用事例として名指しした企業のみで構成した。有報にない企業名は書いていない。
4. **製鉄セグメントの子（children）は事業の内容の製品群をそのまま使った。** 有報は製鉄事業の内訳を条鋼／鋼板／鋼管／交通産機品／特殊鋼／鋼材二次製品／銑鉄・鋼塊他/その他 と列挙しているので、これを会社自身の下位区分として採った。売上収益の内訳は有報に印字されていないので、children の順序は有報の列挙順ではなく読者にとっての分かりやすさ（鋼板→鋼管→条鋼→特殊鋼→交通産機品→鋼材二次製品）で並べた。**children に金額は一切載せていない。**
5. **エンジニアリング／ケミカル＆マテリアル／システムソリューションに children を作っていない。** 有報が下位区分を示していないため。
6. **第101期という期番号は使っていない。** 1950年設立で第101期になる経緯（半期決算の期間があったか）が有報から確認できないため、`fiscalYear` は「2026年3月期」形式のみとし、期番号は sources のタイトルにだけ残した。
7. **日鉄エンジニアリングとカナデビアの経営統合**（重要な契約等 ＊2、2026年2月5日 基本覚書）と**山陽特殊製鋼との合併契約**（2026年5月13日）は、いずれも検討・契約段階で完了していないため history に入れていない。
8. 平均年間給与・株価収益率・1株当たり利益など、主要な経営指標等の推移に並んでいる投資指標は一切転記していない。
