1. **6件の訂正有価証券報告書（2025-07-31提出、第151期〜第156期）— 内容を確認済み。entry には影響しない。**

   訂正報告書本体を開いて「２【訂正事項】」を読んだ。
   - docID: 第151期 `S100WFW3` / 第152期 `S100WFVB` / 第153期 `S100WFV7` / 第154期 `S100WFUZ` /
     第155期 `S100WFUW` / 第156期 `S100WFSJ`（親書類はそれぞれ `S100JMMA` `S100LNII` `S100OB34`
     `S100QZT0` `S100TP5S` `S100W56G`）。
   - 6件とも訂正事項は**ただ1項目**、「第一部 企業情報／第４ 提出会社の状況／４ コーポレート・ガバナンスの
     状況等／(4) 役員の報酬等／② 報酬等の額」のみ。
   - 訂正の中身（第156期の訂正箇所で確認）は、役員報酬の内訳の組み替え。「その他」欄（フリンジ・ベネフィット
     相当額等）を新設し、固定報酬に含めていた額をそこへ移している。執行役計の報酬等の総額は
     6,124百万円 → 6,120百万円、合計は 6,677百万円 → 6,674百万円。
   - 第156期の訂正報告書の DEI は `XBRLAmendmentFlagDEI` = false、`ReportAmendmentFlagDEI` = true。
     財務諸表・セグメント情報・事業の内容・沿革は訂正対象外。
   - **結論**: 役員報酬は本 entry に一切掲載していないため、訂正は entry のどの記述にも影響しない。
     修正再表示でもない（`verify-financials.mjs` の前期有報比較でも8行一致）。entry の出典には代表として
     第156期の訂正報告書 `teisei-yuho-2025` のみを載せた。
2. **名古屋証券取引所の市場区分が確認できなかった**（`status` は `published`。下記のとおり、
   有報は上場金融商品取引所名を「東京、名古屋」としか書かず、市場区分（プレミア／メイン／ネクスト）を
   書いていない。日立の IR「株式情報」ページ（https://www.hitachi.com/ja-jp/ir/stock/information/）も
   「東京、名古屋」のみで区分の記載がない。名証サイト側も、上場会社検索にあたるページを見つけられなかった
   （https://www.nse.or.jp/listing/company/ は有報等提出期限延長会社一覧、
   https://www.nagoya-stock-exchange.com/listing/search/ は404）。他社エントリー（トヨタ・信越化学）が
   「プレミア」を使っていることは知っているが、日立について一次資料で確認できていないので**流用していない**。
   そのため `listings` の名証エントリは `market` を持たない（スキーマ上 `market` は任意）。
   ページには「名古屋証券取引所」とだけ表示され、区分は書かれない。他社エントリから
   「プレミア」を写すことはしていない。東証の「プライム」は有報の記載で確認済み
   （提出会社の経営指標等の注記「最高及び最低株価は…㈱東京証券取引所プライム市場における
   ものであり」）。
