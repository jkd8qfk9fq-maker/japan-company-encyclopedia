# データの出典と利用条件

このプロジェクトが使うデータの取得元ごとに、**利用条件と、まだ必要な対応**を記録する。条件は変わりうる（EDINET は
規約を予告なく変更できる）ので、確認日を添える。**法的な助言ではなく、規約の文言を読んだ記録**である。

| 利用の条件 | コンテンツは**公共データ利用規約（第1.0版）**<https://www.digital.go.jp/resources/open_data/public_data_license_v1.0>（PDL 1.0）の条件で利用できる（I 冒頭） | 下の「PDL 1.0 の表示」 |

| 免責・変更 | API は予告なく停止・性能低下しうる。損害は賠償されない（III 3.1・3.3）。仕様と規約は予告なく変えられる（II 2.1） | 半年に 1 度、この表を規約と照らし直す |

### EDINET コードリスト（`scripts/pipeline/sync-listing.mjs`）

- 規約は、コードリストが「API で取得できないコンテンツ」に当たるかを書いていない。API には、コードリストを返す機能が無い。
- **運営者の決定（2026-10-17）**: 取得は **`--file` による手動**（運営者が EDINET のサイトから保存したファイルを渡す）を既定とする。
  **`--download` の定期実行は導入しない。** API で取得できないコンテンツへの機械取得の可否は、**公式規約の解釈が確定するまで保留**する。
- `--download` は残してあるが、20 時間に 1 回まで・リトライなし・どの定期実行にも入れない。使う前に、解釈の確定を確かめる。
- 解釈を確かめる手段（運営者）: 金融庁への問い合わせ（EDINET のヘルプデスク）。確定したら、ここと JCE-021 を更新する。
